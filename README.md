# SA-UPINN with UDE Refinement (SA-UPINN-UDE)

A two-stage scientific machine learning framework for discovering unknown terms in mechanistic differential equation models from observational data. SA-UPINN-UDE combines self-adaptive physics-informed learning with universal differential equation refinement to improve agreement between numerically simulated trajectories and observed data.
